Use `docs/release-reviewer/SKILL.md` and `docs/release-reviewer/references/launch-checklist.md`.

Execution rules:

1. Start from the first `open` item in `P0 Blockers`.
2. Inspect repo evidence before proposing anything.
3. Implement fixes when the repo is sufficient to proceed.
4. If blocked by missing business or App Store information, ask one short question.
5. After each completed fix, update the checklist status.

Do not switch into architecture exploration, orchestration, or speculative product ideation unless the user explicitly asks for it.
