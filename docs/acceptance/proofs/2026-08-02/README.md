# Докази 2026-08-02 для повторного qa: observer-timezone + observer-calendar-day

Метод (ЧЕСНО, для вердикту qa): це НЕ iOS-симулятор. Chromium (playwright-core
проєкту) з `timezoneId: America/Los_Angeles` + `page.clock.install` на момент
із приймання **2026-08-01T06:30:00Z** (LA: 31 липня 23:30; Київ: 1 серпня 09:30),
локація — дефолтний Київ, онбординг пропущено так само, як у генератора
App Store-шотів (`tests/visual/appstore-shots.spec.js`). В'юпорт 440×956 @3x.
Скрипт: збережено в сесії консультанта (scratchpad qa-proofs.mjs); відтворюється
тими самими параметрами.

Чи достатній браузер із керованим часом замість симулятора — рішення qa.
Аргумент «за»: перевіряється логіка поясів (Intl + skyTime.js), яка в браузері
і в WebView Capacitor одна й та сама; момент відтворено точно, чого реальний
симулятор не вміє без підміни системного годинника.

## Файли
- `A1-sky-top-LA-device-2026-08-01T0630Z.png` — шапка SkyPage: «Saturday,
  August 1» + чип Kyiv при пристрої в LA (там ще 31 липня). Критерій A1
  calendar-day: заголовок за поясом локації.
- `A1-sky-calendar-LA-device-2026-08-01T0630Z.png` — календар Місяця:
  **August 2026, підсвічене 1** (до фікса показував липень). A1/B-розділ.
- `B1-sky-observe-LA-device.png` — «Best time to observe 11:20 PM – 02:48 AM»,
  тур ночі, часи за Києвом при LA-пристрої. Критерій B1 observer-timezone.
  Увага qa: мітки «UTC+3» у кадрі не видно — якщо B2 вимагає її саме тут,
  перевір скролом нижче або зафіксуй окремо.
- `D4-offline-*.png` — офлайн-прогін: мережа вимкнена (`context.setOffline`)
  після завантаження, обхід Home/Sky/Journal; `pageerror`-ів: **0**.
  Обмеження методу: дев-сервер, не зібраний бінарник — переінсталяцію
  без мережі це не покриває.
