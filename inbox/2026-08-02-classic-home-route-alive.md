# Мертвий маршрут `/classic-home` тримає весь старий астрологічний Home

Знайдено 2026-08-02 під час Т-B. Поза обсягом — не чіпав.

`src/router/routes.js:10` — `{ path: 'classic-home', name: 'classicHome',
component: GetStartedPage.vue, meta: { tab: 'arcana' } }`. `GetStartedPage`
рендерить `components/main/LandingScene.vue` — це старий Home білда 62:
«Moon in <знак>» (`LandingScene.vue:603`), картка сонячного знака (`:673`),
картка **числа дня** (`:684`), картка ретро-Меркурія (`:694`), прев'ю гороскопу,
прогрес по таро/гороскопу.

Що важливо: **`meta.tab = 'arcana'`** — тобто маршрут формально належить
головному табу. Т-B прибрав астрологію з `SkyHomePage` / `SkyPage` /
`JournalPage`, але цей екран лишився недоторканим.

Ризику для ревʼю **скоріше немає**: посилань на `classicHome` в коді нуль
(`grep -rn "classicHome\|classic-home" src/` дає лише сам `routes.js`), а в
нативному білді ревʼюер не має адресного рядка. Але це 1200+ рядків мертвого
компонента в бандлі і маршрут, який будь-який майбутній редірект може оживити.

Питання продакт-оунеру: видаляти маршрут (і, можливо, `GetStartedPage` +
`LandingScene`) чи лишити до вердикту гейта разом із рештою 9 дивінаційних
екранів. Звіт стратега (розділ 6) уже назвав це ширшою проблемою «продукт став
двома продуктами» — окреме рішення після апруву, не перед сабмітом.
