# Arcana Insight — AI Command Center
## Повна візія. Максимальна версія.

> Це не просто набір скриптів. Це автономна система яка живе поряд з проектом,
> думає про нього 24/7, і перетворює тебе з розробника який гасить пожежі
> на розробника який тільки приймає рішення.

## Шар 1 — Code Agents (робота з кодом)

### 🏗 Builder Agent
Найпотужніший агент. Отримує опис фічі → сам пише код → сам тестує → відкриває PR.

**Що вміє:**
- Читає весь проект перед тим як щось писати (знає архітектуру, стиль, конвенції)
- Додає i18n ключі в `uk.json` і `en.json` одночасно
- Слідкує за стилем: Options API, BEM CSS, safe-area insets — точно як у проекті
- Після написання — сам запускає тести і виправляє якщо щось впало
- Відкриває PR з описом що і чому зробив

**Як використовуєш:**
```
"Зроби сторінку сумісності для двох знаків з анімацією результату"
→ через 10 хвилин: готовий PR
```

---

### 🔍 Code Intelligence Agent
Постійно аналізує кодобазу. Знає кожен файл.

**Що відстежує:**
- Закоментований код (`//display: grid`, `// TODO`, `// not implemented`)
- Файли-дублі (`CompatibilityPage 2.vue`, `supabaseNative 2.ts`)
- Компоненти які є в `src/` але не підключені до роутера
- i18n ключі які є в одній мові але відсутні в іншій
- Мертвий код — функції які ніколи не викликаються
- CSS класи які описані але не використовуються
- Незакриті Vue реактивні підписки (memory leaks)

**Вихід:** Пріоритизований список. "Це треба зробити до релізу. Це після."

---

### 📐 Architecture Guardian
Стежить щоб архітектура не деградувала з часом.

**Що перевіряє:**
- Бізнес-логіка не просочується в компоненти (має бути в helpers/)
- Stores не стають "богами" — один store = одна зона відповідальності
- Edge functions не перевищують розумний розмір (>300 рядків = сигнал)
- Немає прямих fetch() з компонентів (має йти через services/)
- Capacitor API викликається тільки після platform check

## Шар 2 — Quality Agents (якість)

### 🧪 Test Intelligence Agent
Не просто запускає тести. Думає про тести.

**Що вміє:**
- Запускає Jest після кожного збереження файлу
- Якщо тест впав — пояснює **чому** простою мовою, не stack trace
- Бачить що ти написав нову функцію без тесту → сам пише тест
- Аналізує coverage: "ця функція в dailyCardCore.js не покрита — критична для релізу"
- Перед релізом: запускає повний suite і дає "зелене світло" або список що треба закрити

---

### 📸 Visual Regression Agent
Бачить апку очима.

**Що вміє:**
- Запускає iOS симулятор, робить скриншоти всіх екранів
- Порівнює "до" і "після" змін — pixel-perfect diff
- Тестує на різних розмірах: iPhone SE (маленький), iPhone 15 Pro Max (великий)
- Знаходить: елементи що виїжджають за екран, тексти що обрізаються, overlap елементів
- Перевіряє safe-area на всіх екранах автоматично

---

### 🌐 i18n Completeness Agent
Жодного пропущеного перекладу.

**Що вміє:**
- Порівнює `uk.json` і `en.json` — знаходить ключі що є в одному але нема в іншому
- Автоматично перекладає відсутні ключі (з Claude, не Google Translate — якість інша)
- Перевіряє що переклади не виходять за межі UI елементів (довгі рядки)
- Знаходить hardcoded тексти в компонентах які треба винести в i18n

## Шар 3 — Runtime Agents (виконання)

### 🪲 Supabase Intelligence
Повне розуміння бекенду в реальному часі.

**Що моніторить:**
- Всі 16 edge functions — latency, error rate, успішність
- OpenAI API calls: скільки токенів витрачається, яка вартість, де можна оптимізувати промпти
- OpenRouter fallback: коли спрацьовує, чому, чи варто переглянути
- База даних: повільні запити, таблиці що ростуть несподівано швидко
- Cron jobs: `build-astro-context` і `generate-horoscopes` — чи відпрацювали вночі

**При помилці:**
```
🔴 tarot-reading впав 5 разів за останні 10 хвилин
Причина: OpenAI rate limit (429)
Рішення: додати exponential backoff в рядку 34
Я написав фікс — хочеш застосувати? [Так] [Показати код]
```

---

### 📱 RevenueCat Intelligence (після релізу)
Розуміє монетизацію глибше ніж дашборд RevenueCat.

**Що аналізує:**
- Конверсія trial → paid по кожному екрану онбордингу
- В який момент юзери закривають пейвол (scroll depth)
- Які фічі найчастіше використовують перед підпискою
- Churn: чому люди скасовують (якщо є дані з reviews)
- A/B порівняння різних варіантів paywall copy

---

### 🔥 Firebase Deep Analytics (після релізу)
Не просто цифри — розуміння поведінки.

**Що аналізує:**
- User journey: яким шляхом йдуть від реєстрації до першої покупки
- Drop-off points: де саме юзери йдуть і чому (порівнює з кодом того екрану)
- Feature adoption: які фічі взагалі не відкривають (можна прибрати або переробити)
- Retention cohorts: юзери що роблять X в перший день — чи повертаються на 7й
- Correlation: настрій (mood-inline) vs retention — чи є зв'язок

## Шар 4 — Product Agents (продукт)

### 🎯 Launch Readiness Agent
Знає чи готова апка до релізу.

**Постійно відстежує:**
- Всі роути в `routes.js` — чи є відповідна сторінка, чи вона не порожня
- RevenueCat: чи підключений до реального аккаунту (не sandbox)
- Apple Sign In: чи налаштований в Xcode entitlements
- Privacy policy і Terms: чи є живі URL (App Store вимагає)
- Push notifications: чи зареєстровані APNs certificates
- App icons: чи є всі розміри (Apple вимагає точний набір)
- Screenshot комплект для App Store: чи готовий

**Вихід:**
```
Launch Readiness: 67%
Блокери (3): RevenueCat prod key, Privacy URL, APNs cert
Не критично (5): кілька порожніх i18n ключів, email editing
```

---

### ✍️ Content Intelligence Agent
Думає про контент апки.

**Що вміє:**
- Аналізує якість AI-генерованих гороскопів (чи не повторюються, чи є глибина)
- Порівнює таро інтерпретації між картами — чи достатньо різноманітні
- Знаходить де можна покращити промпти edge functions для кращих результатів
- Після релізу: які карти/гороскопи найчастіше шерять юзери = що резонує

---

### 🏪 App Store Optimization Agent (перед релізом)
Максимізує шанс знайти апку і завантажити.

**Що робить:**
- Аналізує keywords конкурентів (Labyrinthos, The Moon tarot, Co-Star)
- Генерує варіанти опису з різними keyword стратегіями
- Перевіряє title і subtitle на довжину (Apple обмеження)
- Аналізує скриншоти конкурентів — що показують, який hook
- Пропонує що показати на кожному зі скриншотів
